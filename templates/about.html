About LearnLift

An AI-Based Student Performance Prediction and Behaviour Analysis System

About Our Project

🎯 Problem Statement

Students may struggle academically without being identified early. LearnLift analyzes student data to predict academic outcomes and help identify students who may need additional support.

🚀 Project Objective

The objective is to develop a machine learning system that predicts student results and analyzes learning behaviour using available student information and activity data.

🤖 Machine Learning Algorithms

Random Forest Classifier: Predicts student outcomes such as Pass, Fail, Distinction, and Withdrawn.

K-Means Clustering: Groups students according to learning activity patterns for behaviour analysis.

📊 Dataset

LearnLift uses the Open University Learning Analytics Dataset (OULAD), which contains student information, assessment records, and online learning activity data.

💻 Technologies Used

Tools and technologies used in the project:

Python Pandas Scikit-learn Random Forest K-Means Flask HTML CSS JavaScript Joblib

📈 Expected Outcome

The system provides student outcome predictions, model performance information, and behaviour groups through a web interface. These results can support early identification of students who may need academic assistance.
