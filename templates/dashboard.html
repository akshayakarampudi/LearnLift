About the Dashboard

This dashboard summarizes student outcomes from the Open University Learning Analytics Dataset (OULAD). LearnLift uses assessment results and online learning activity to predict a student's final course result.

The charts and evaluation metrics help explain the dataset and assess the model's performance on test data.
