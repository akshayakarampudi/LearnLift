LearnLift

EDTECH  ·  MACHINE LEARNING

Spot learning challenges early. Turn student data into timely support.

The problem

Online learning platforms collect assessment results and activity data, but it can be difficult to notice learners who are struggling. Finding warning signs sooner gives educators a chance to offer help before a student disengages.

The project — what it does

LearnLift uses student profile, assessment and online activity features with a trained machine-learning model to predict an outcome category. A separate clustering workflow groups learners by activity patterns to support further analysis.

IdentifyPotential withdrawal / dropout concern

ExploreModel metrics and prediction probabilities

Why it matters now. Learning analytics can help educators make more informed, supportive decisions — with predictions treated as signals for help, not labels for students.

Project principles

  • Use assessment and activity patterns to support early attention.
  • Evaluate model performance and be transparent about prediction uncertainty.
  • Protect student privacy and avoid using predictions to stigmatise learners.
