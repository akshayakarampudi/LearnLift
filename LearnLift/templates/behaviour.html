How Student Behaviour is Identified

LearnLift uses K-Means clustering to group students with similar learning activity patterns.

Assessment Average Score Average assessment performance
Assessment Count Number of recorded assessments
Total Clicks Total online learning interactions
Active Days Number of days with recorded activity

Student Behaviour Groups

The clustering model identifies three groups based on similarities in the selected academic and learning activity features.

  • Highly Active Learners: relatively higher learning activity.
  • Moderate Activity Learners: intermediate learning activity.
  • Low Activity Learners: relatively lower learning activity.

Clustering Algorithm

Algorithm: K-Means Clustering

Number of Groups: 3

The features are standardized before clustering so that features with larger numerical values do not dominate the clustering process.
