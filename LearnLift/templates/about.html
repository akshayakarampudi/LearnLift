About LearnLift

LearnLift is an AI-based student performance and dropout prediction system designed to identify student learning outcomes using academic and online learning activity data.

Why LearnLift?

Problem & Objective

⚠️

Problem Statement

Educational institutions collect large amounts of student academic and online learning data. However, identifying students who may fail, withdraw, or need additional academic support can be difficult using traditional methods.

🎯

Objective

LearnLift uses machine learning to predict student performance outcomes and provide an early indication of possible dropout risk, helping educators identify students who may need support.

Machine Learning

Our Prediction Model

🌲

Random Forest Classifier

LearnLift uses a Random Forest classification algorithm to predict four possible student outcomes based on academic performance and learning activity.

Pass Fail Withdrawn Distinction

How It Works

Project Workflow

01

Data Collection

Collect student information, assessment data, and online learning activity from the OULAD dataset.

02

Data Processing

Clean and combine the different datasets to prepare the information for machine learning.

03

Feature Engineering

Create useful features such as assessment average, assessment count, total clicks, and active days.

04

Model Training

Train a Random Forest model using the processed student data and learning features.

05

Prediction

Use the trained model to predict the student's expected academic outcome.

06

Result Analysis

Display the predicted outcome, confidence, probabilities, and dropout risk to the user.

🚀

Helping Students Succeed

LearnLift combines student data and machine learning to provide meaningful insights that can support early identification of students who may need help.
