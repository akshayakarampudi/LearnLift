📚 About LearnLift

Problem Statement

Students may struggle academically without being identified early. LearnLift uses Machine Learning to analyze student information and predict academic outcomes.

Objective

The objective of LearnLift is to develop a Machine Learning based system that can predict student academic performance from available student information.

Machine Learning Algorithm

This project uses the Random Forest Classifier for multi-class student result prediction.

Dataset

The project uses the Open University Learning Analytics Dataset (OULAD).

Technologies Used

Python Pandas Scikit-learn Random Forest Flask HTML CSS Joblib
